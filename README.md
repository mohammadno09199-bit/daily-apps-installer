# 🚀 ابزار جامع نصب و پیکربندی پس از نصب (Setup Apps & Tweaks)

یک اسکریپت پیشرفته، امن و کراس‌پلتفرم با زبان **پایتون** برای خودکارسازی فرآیند نصب نرم‌افزارهای ضروری و اعمال تنظیمات حیاتی سیستم‌عامل پس از نصب تازه (Clean Install).

این ابزار از **`winget`** در ویندوز ۱۰/۱۱ و **`apt`** در توزیع‌های لینوکس مبتنی بر دبیان/اوبونتو پشتیبانی می‌کند.

---

## ✨ ویژگی‌های کلیدی

* **طراحی ماژولار و ایمن:** هیچ تغییری بدون تأیید یا انتخاب صریح شما اعمال نمی‌شود.
* **منوی تعاملی (Interactive Menu):** امکان انتخاب یا لغو انتخاب برنامه‌ها و تنظیمات با شماره‌گذاری ساده در ترمینال.
* **حالت پیش‌نمایش (`--dry-run`):** بررسی و تست دستورات پیش از اجرای واقعی بدون اعمال هیچ‌گونه تغییری روی سیستم.
* **ثبت لاگ کامل (`install.log`):** ذخیره تمام مراحل، خطاها و خروجی‌ها در فایل لاگ جهت عیب‌یابی آسان.
* **مدیریت هوشمند خطاها:** بروز خطا در نصب یک برنامه، مانع از ادامهٔ کار بقیه بسته‌ها یا تنظیمات نمی‌شود.
* **تنظیمات اختصاصی ویندوز:** ساخت نقطه بازیابی (Restore Point)، غیرفعال‌سازی Fast Startup (بدون غیرفعال کردن خودِ Hibernate)، نمایش پسوند فایل‌ها و افزودن استاندارد کیبورد فارسی (`Persian Standard`).

## 📥 روش نصب و استفاده

1. مطمئن شوید که پایتون ۳.۸ یا بالاتر روی سیستم شما نصب است.
2. اسکریپت `setup_apps.py` را دانلود کرده یا درون پوشهٔ دلخواه قرار دهید.

### ۱. اجرای تعاملی (پیش‌فرض)
بدون هیچ پارامتری، منوی انتخاب برنامه‌ها و تنظیمات نمایش داده می‌شود:
```powershell
python setup_apps.py
```

### ۲. استفاده از پریست‌های آماده (Presets)
برای نصب سریع مجموعه‌های استاندارد (مانند نرم‌افزارهای روزمره یا توسعه‌دهنده):
```powershell
# نصب بسته‌های روزمره
python setup_apps.py --preset daily

# نصب بسته‌های توسعه‌دهنده
python setup_apps.py --preset developer

# نصب تمام بسته‌های موجود
python setup_apps.py --preset full
```

### ۳. پیش‌نمایش قبل از اجرا (Dry-Run)
برای اینکه ببینید اسکریپت دقیقاً چه دستوراتی را اجرا خواهد کرد:
```powershell
python setup_apps.py --preset daily --dry-run
```

### ۴. اعمال تنظیمات اختصاصی ویندوز
می‌توانید برنامه‌ها را نصب کرده و همزمان تنظیمات سیستمی ویندوز را نیز اعمال کنید (توصیه می‌شود ترمینال را به صورت **Run as administrator** باز کنید):
```powershell
python setup_apps.py --preset daily --settings restore-point fast-startup-off show-extensions persian-standard
```

---

## 📋 لیست تنظیمات قابل‌تنظیم در ویندوز (`--settings`)

* `restore-point`: تلاش برای ساخت سیستم Restore Point پیش از اعمال تغییرات.
* `fast-startup-off`: غیرفعال کردن قابلیت Fast Startup (جلوگیری از باگ‌های برق و کیبورد در لپ‌تاپ‌ها).
* `show-extensions`: نمایش پسوند پسوند فایل‌ها (File Extensions) در File Explorer.
* `persian-standard`: افزودن استاندارد کیبورد فارسی (`Persian Standard`) برای کاربر جاری.
* `windows-update`: میانبر باز کردن پنل Windows Update جهت بررسی به‌روزرسانی‌ها.
* `activation`: باز کردن صفحهٔ وضعیت فعال‌سازی ویندوز.

## 🛠️ نکات فنی برای اجرا
* **در ویندوز:** مطمئن شوید ابزار `winget` (بسته App Installer از مایکروسافت استور) روی سیستم شما فعال است.
* **در لینوکس:** برای نصب بسته‌ها از طریق `apt`، اسکریپت را حتماً با دسترسی روت اجرا کنید:
  ```bash
  sudo python3 setup_apps.py
  ```
